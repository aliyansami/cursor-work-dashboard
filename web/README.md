# Jarvis Ops Console (`web/`)

Vite + React + TypeScript. Package manager: **yarn**.

```bash
yarn
yarn dev      # http://localhost:5173
yarn build
yarn preview
```

Live data snapshot: [`public/data/dashboard.json`](public/data/dashboard.json) — Agent rewrites this on “Hey Jarvis, refresh”. Click **Reload** in the header after a refresh.
