# Security Policy

## Reporting

If you find a secret or private data accidentally published in this repository, open a private security advisory or email the maintainer, and open a PR that removes it immediately.

## Rules for contributors

- Never commit GitHub PATs, Slack tokens, Google OAuth secrets, `.env` files, or real private Slack/email content.
- Demo canvas data must stay fictional.
- Prefer fine-grained PATs stored only in Cursor MCP settings.
